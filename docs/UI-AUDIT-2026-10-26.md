# UI audit, 2026-10-26

## Dialog families

| Family | Current behaviour / scope |
| --- | --- |
| Launch chooser, menus, settings panel, login, checklists, clipboard | All enter through `window/src/main.rs`, which sets the explicit font configuration before dispatching. The font-loading fix therefore covers these branches, not just the launch chooser. This is a code-path audit, not visual certification of every dialog on every desktop. |
| Already-running / throwaway-running menus | Host-initiated navigation now has no guard. Arrow navigation must not restart a three-second timer. |
| Network, microphone and other permission questions | Keep the anti-click-through guard. Security decisions are not ordinary navigation. |
| Force-close / network-switch confirmation | Retain their existing guard because they can interrupt running programs. |
| On-window frame and permission panels | Native Wayland renderer with a fixed embedded font; independent of Iced/fontconfig. |
| File pickers, desktop Open With portals, kdialog fallbacks | External desktop components, not covered by the Iced font configuration or a finished unified chooser. |

## Clipboard changes in this batch

- Tray-manager regular entries, including images, get explicit **Copy for paste**.
  This uses the existing selection API and requires manual Ctrl+V in the target;
  it is not automatic point-targeted insertion or a private container buffer.
  A visible warning names the shared desktop clipboard/CopyQ boundary.
  Password export retains its separate confirmation.
- The manager really closes its Wayland surface while typing and reopens it
  afterwards, retaining its state and theme. A no-op request to hide a winit
  surface was not sufficient on Wayland.
- Typing rejects multiline entries by default. Explicit choices replace newlines
  with spaces or send Enter. CRLF is normalized; other control characters remain
  rejected. Shift+Enter/Ctrl+Enter are not silently substituted: their meaning
  depends on the target application. Ordinary clipboard paste is preferable for
  multiline text and necessary for images.

## Verification

- Core unit tests: 1106 passed; window unit tests: 70 passed.
- Production Nix build passed using the already-fetched pinned inputs.
- Headless Wayland typing smoke passed from both the tray manager and frame
  history: point selection, actual hiding during typing, reopening and theme
  preservation. Image eligibility is unit-tested, not end-to-end image paste.
- Startup VM passed with 1000 extra user font entries. Process-to-surface
  samples were 2042, 651 and 670 ms under software virtualization; these are
  guest measurements, not a host startup guarantee.

## Confirmed open priorities

1. Wire the private active-clipboard broker into Wayland and X11, including
   images, explicit host import/export and automatic tray-to-selected-window
   paste. Histories being separate does not isolate active selections.
2. Fullscreen permission visibility. Network requests now emit an informational
   critical notification without grant actions or focus stealing, once per
   opened question. Desktop notification/DND policy can still hide that notice;
   this is not a guarantee of globally topmost permission windows.
3. Frame opacity: the rounded top now has a unified image containing its
   rings, corner caps, title and buttons; it does not retain overlapping top
   backgrounds. See `UNIFIED-ROUNDED-TOP.md`. Square/tag and bounded fallback
   paths remain separate; this is not a claim of universal compositor-opacity
   equivalence for every path.
4. Restore tray-only applications when selecting “switch to running”, not just
   focus an already-mapped window. Avoid application allowlists.
5. Destination/connection-level paranoid firewall, including expiring rules.
   The current question grants/denies the launch/program's network as a whole.
6. Finish the English-source localization, unified link/application chooser and
   application-theme overrides. Chain/proxy route controls already exist in the
   settings panel; broader route lifecycle/DNS/failure integration remains part
   of the network roadmap.
