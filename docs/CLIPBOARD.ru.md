# Буфер обмена по контейнерам

Скопированное в своём контейнере программа читает свободно. Скопированное в
другом контейнере или на хосте — только когда человек вставляет.

## Как

Посредник Wayland каждого запуска (`rust/src/clip.rs`, `wl_frame.rs`):

- **Метит скопированное его программой.** У `wl_data_source` и источника
  выделения появляется ещё один тип, `application/x-cellward-clip-<секрет>`:
  секрет экземпляра запуска (`$XDG_RUNTIME_DIR/vpn-zones/clip/`, создаётся
  при первом запуске, читает только пользователь). На запрос этого типа
  ответа нет, свои метки программы отбрасываются, и ни одна программа под
  посредником метку не видит.
- **Читает метку предложенного.** Предложение с меткой своего экземпляра —
  своё, любое другое — чужое.
- **Отдаёт чужое** в течение двух секунд после вставки человеком: Ctrl+V,
  Ctrl+Shift+V, Shift+Insert — по раскладке самой клавиатуры, в любой
  раскладке — или щелчка средней кнопкой для выделения; и при перетаскивании
  на программу. Предложенные типы видны: программа знает, что вставить есть
  что.
- **Не открывает data-control.** Читать буфер без фокуса контейнерам не дано
  вовсе.

## Пока нет

- Вставка чужого из меню самой программы ничего не даёт. Следующее — кнопка
  рамки, которая вставляет.
- Программа хоста не под посредником читает всё и все метки, как и раньше.

## Дальше: история

Шифрование на диске, раздельно по контейнерам, вызов по клавише; хранить
сколько угодно; мгновенный поиск по десяткам миллионов записей (индекс на
диске через `mmap`), по дате и по запросу из блоков — текст, цифры,
диапазоны, начало и конец — с выражением словами и живой проверкой.
